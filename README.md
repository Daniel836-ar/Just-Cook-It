# **Just Cook It** 
 Данный проект создан с целью решить одну наболевшую для многих проблему : "Что приготовить из того , что есть ?". Это приложение ищет рецепты , на которые вам хватает ингредиентов. В данный момент проект находится в стадии разработки и представляет из себя утилиту, которая в будущем должна стать сайтом :wink:.
##  Цель проекта
Проект разрабатывается в **учебных целях** для:
*   Освоения современного Java-стэка (Spring Boot, Hibernate, PostgreSQL).
*   Применения теоретических знаний на практике.
*   Выполнения курсовой работы в университете.(Уже сдали :smirk:. )
*   Создания полезного и понятного инструмента.

## Установка 
В текущей версии проект требует локального развёртывания PostgreSQL с заполненной базой данных. В будущем планируется полная контейнеризация проекта (Docker Compose) для упрощения запуска. 
## Использование 
При запуске вас встретит такое окно : 
```
--- Поиск рецептов по ингредиентам ---
Введите название ингредиента (или 'стоп' для завершения): 
```
После ввода слова "рис" (без разницы в каком регистре), появится данная строка : 
```
Введите количество, данный ингредиент измеряется в "грамм": 
```
Программа даже скажет , в чём вводить данные :), в данный момент в граммах. После ввода количества (есть проверка на корректность введённого числа) всё повторится до тех пор , пока не будет введено слово "стоп". После остановки мы увидим список ингредиентов , которые мы выбрали, и список самих найденных рецептов , для которых хватит ингредиентов :
```
--- Поиск рецептов по ингредиентам ---
Доступные ингредиенты:
  - рис: 600 грамм
  - помидор: 5 штук
  - огурец: 2 штук
  - яйцо куринное: 3 штук
Найдено рецептов: 4
 - Яишница, инструкция по приготовлению: Три яйца на сковороду и жарить на среднем огне 5 минут
 - Яйца с рисом, инструкция по приготовлению: два яйца на сковороду и жарить на среднем огне 5 минут, а потом добавить готовый рис
 - Яйца с помидором, инструкция по приготовлению: Три яйца и один помидор на сковороду, и жарить на среднем огне 5 минут
 - салат из огурцов и помидоров, инструкция по приготовлению: Произвольно нарезаем огурцы и помидоры , кладём все вместе в одну миску
```
Все рецепты созданы для показа работы программы.
